# 웹페이지 포트 기록부

pixel-agents가 소유한다. **상시 포트만** 적고, 이 표는 pixel-agents 세션만 고친다.
다른 프로젝트는 상시 포트를 추가·변경·폐지할 때 superagent를 통해 요청한다.

실행 여부·PID는 pixel-agents가 8760–8780 대역의 listener를 직접 조사해서 채운다.
표에 없는 listener는 `일회성`으로 자동 표시되므로 따로 적지 않는다.
